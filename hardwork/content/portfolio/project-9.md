#### Project Description
We attempt to understand what components best predict goal-scoring opportunities. Using five machine learning approaches; logistic regression, reduced logistic regression, classification trees, bagging, and random forests, we were able to estimate models that correctly classified the result of a shot on target more than 80\% of the time.
